How to find hardcoded numbers in an Excel model

The most expensive cell in a spreadsheet is the one that looks right today and cannot be updated tomorrow: a rate typed directly into a formula.

Why this specific pattern hurts

Two formulas that look equally healthy:

A:  =B4 * $B$2        B:  =B4 * 0.2

A recalculates when the margin assumption in B2 changes. B does not. When the board changes the target margin and someone updates the input cell, A moves and B stays at 20%. The model now contains two different versions of the truth, and the difference shows up as an unexplainable variance three sheets away.

Nobody does this maliciously. It happens when someone quickly checks a number, or when a rate arrives by email and gets typed straight into the cell that needs it. Then the file is saved, and the shortcut becomes permanent.

Find them with Show Formulas

  1. Press Ctrl + ` (grave accent) to display formulas instead of results on the active sheet.
  2. Scan each formula for arithmetic against a numeral: * 0.2, / 1.08, * 1.035.
  3. Repeat per sheet — Show Formulas is per-sheet, not per-workbook, which is exactly how hardcodes survive a review.
  4. Press Ctrl + ` again to restore results.

A faster complement: Home → Find & Select → Go To Special → Formulas highlights every formula cell in the sheet, which makes a long sheet scannable at a glance.

Tell a conversion from an assumption

Not every literal is a bug. The distinction matters, because flagging everything is as useless as flagging nothing:

LiteralUsually meansAction
* 1000, / 12, * 2Unit or period conversion — structural, rarely changesUsually fine. Consider a comment.
* 0.2, * 0.15, - 0.03A rate, margin, discount or tax — a business assumptionMove to a labelled input cell.
* 1.08, * 1.035Indexation or uplift applied to a figureMove to an input cell so it can be updated by year.
Any literal used in a comparisonA threshold or toleranceMove it, or at least name it.

The rule of thumb: if a reasonable person could disagree about the number next quarter, it does not belong inside a formula.

Fixing them without breaking the file

  1. Create one clearly labelled input area — a dedicated sheet is cleanest — with a name and a unit for each assumption.
  2. Replace the literal with an absolute reference: B4 * $Assumptions.$B$7.
  3. Define a range name for each assumption. Formulas then read B4 * Margin, which is both safer and self-documenting.
  4. Reconcile before and after: the reported totals should be identical at the moment of the change. If they are not, you have found an assumption that was already wrong.
Check the whole workbook, not the sheet you are looking at Doing this by eye across every tab is where most reviews quietly give up — and the hidden sheet is the one nobody checks.
